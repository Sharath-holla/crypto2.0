# Phase 7A Experiment

Phase 7A exists because the complete Phase 7 matrix was too expensive for the first real cloud
run. It is a separate configuration and scientific experiment, not a mutation of the full Phase 7
contract.

## Included

- Realized `core_universe_v1` Core20, CORE view only;
- all 16 canonical rolling folds;
- A6 feature schema (54 native plus completed 12h/1d context as defined by the catalog);
- four horizons × two target types;
- G0, C0, P0, H0 plus G0 symbol-ID and unbalanced controls.

That is exactly `4 horizons × 2 targets × 6 architecture/control variants = 48` primary A6
specifications per fold. The base four architectures retain symbol-balanced weighting for G0/C0/H0
as configured; P0 is per-symbol.

## Deferred

- six G0 feature-ablation specifications A0–A5 at 60m raw;
- four G0 higher-timeframe controls BASE/BASE+12h/BASE+1d/BASE+12h+1d;
- the separate EXPANDING view.

Phase 7A therefore provides a valid first Core20 retrospective OOS architecture experiment if it
eventually completes, but it is not the full Phase 7 robustness study. It does not authorize Phase
8, paper trading, or live execution. Current result remains **not evaluable** because Fold 1 has
0/48 completed reports.
